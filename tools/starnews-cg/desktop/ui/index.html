QUICK START

From preview to program.

  1. Download and extract the package. On Windows, run Start-Studio.bat (Python 3 required), or serve the folder from XAMPP for standalone graphics.
  2. In the local studio, choose a graphic and edit its content. Open output or copy its URL.
  3. In OBS or vMix, add that URL as a browser source at 1920 × 1080, 60 FPS. The station ID and coming-up slate have backgrounds; other scenes have alpha.
  4. The included Python server relays cues between the studio and OBS. Static hosting and file mode support standalone animations; cross-tab controls only work inside the same browser.

Weather is manually entered sample data, not a live feed. Replace it before airing. The station ID is a branding slate; add any required call signs and locations in the editable identification line.
