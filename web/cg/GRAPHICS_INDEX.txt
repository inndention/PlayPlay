================================================================================
                      CUSTOMIZATION GUIDE
================================================================================

To change colors globally, edit :root in any HTML file:

  :root {
    --primary:   #00D9FF;      /* Cyan - change to brand color */
    --secondary: #A855F7;      /* Purple - change to brand accent */
    --accent:    #FFD700;      /* Gold - highlight color */
    --dark:      #0F172A;      /* Background */
    --white:     #E8E8E8;      /* Broadcast-safe white */
  }

Font customization (CSS):
  font-family: 'Arial', 'Helvetica Neue', sans-serif;
  (Change to your preferred broadcast-safe font)

Animation timing:
  animation: slideIn 0.5s cubic-bezier(0.22, 1, 0.36, 1) forwards;
  (0.5s = duration. Adjust as needed, keep ≤1.2s for broadcast)

DOCUMENTATION:

TROUBLESHOOTING:
  Q: Graphics not showing?
  A: Check server is running (npm start), port 3060 accessible

  Q: Colors look washed out?
  A: Confirm display is set to Rec.709 color space

  Q: Animation stuttering?
  A: Check system GPU/CPU usage, reduce particle count if needed

  Q: Can't copy URL in gallery?
  A: Ensure JavaScript is enabled in browser

REPORTS:
  Issues with any graphic:
  1. Open browser console (F12)
  2. Check for JavaScript errors
  3. Verify URL parameters are correct
  4. Test in different browser if possible
