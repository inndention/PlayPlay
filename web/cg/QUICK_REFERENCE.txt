🆘 QUICK TROUBLESHOOTING

  Q: Server not starting?
  A: Check port 3060 is free (netstat -an | grep 3060)

  Q: Graphics not loading?
  A: Verify server running (npm start) and URL is correct

  Q: Colors look off?
  A: Confirm monitor is set to sRGB/Rec.709 color space

  Q: Animations stuttering?
  A: Close other apps, check CPU/GPU usage
