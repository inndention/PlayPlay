# Design notes (not published)

Many comments in the source cite files under `docs/plans/` (for example `docs/plans/ux-buttons.md`) or "the lane design
notes". Those notes were working documents from the project's agent-assisted development: implementation logs, slice plans
and measurements tied to one station's machines. They are not part of this repository.

Everything needed to build and use PlayPlay is in the top-level [README](../../README.md) and the guides in
[docs/](../README.md). When a comment points at a plan, read it as a pointer to the reasoning behind the code, not as a
file you are missing.
